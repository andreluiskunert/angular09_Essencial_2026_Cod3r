# Curso Angular 9 – Desenvolvimento de SPA

Curso prático e objetivo de **Angular 9**, mantido pelo Google, focado na construção de aplicações **SPA (Single Page Applications)** modernas, com fundamentos sólidos e aplicação real.

- **Idioma:** Português (com legendas)
- **Aulas:** 17
- **Duração:** 2 horas de vídeo
- **Alunos:** +29.000

## 🚀 Conteúdos Abordados
- Componentes
- Módulos

- Services

- Pipes
- Navegação
- Observables
- Consumo de API REST

Todo o conteúdo é aplicado na construção de uma **aplicação prática** ao longo do curso.

## 🅰️ O que é Angular?
Angular é um framework open source para desenvolvimento de aplicações web baseadas em **SPA**, oferecendo alta performance, organização de código e experiência semelhante a aplicações desktop.

## 📚 O que você aprenderá
- Desenvolver aplicações com Angular 9
- Aplicar os principais conceitos do framework
- Criar uma aplicação CRUD (Cadastrar, Listar, Atualizar e Excluir)
- Trabalhar Angular de forma prática e objetiva
